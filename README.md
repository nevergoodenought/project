# Поиск по словарям

Небольшое Flask-приложение для поиска слов по нескольким CSV-словарям. Данные
загружаются в PostgreSQL, а само приложение запускается через Docker Compose.

Для публичной версии я оставил демо-словари, чтобы проект можно было спокойно
показывать и загружать на GitHub. Полные словари в репозиторий не входят.

## Что есть в проекте

- Flask-приложение с веб-интерфейсом поиска
- PostgreSQL с таблицами для разных словарей
- загрузка данных из CSV
- сборка общего файла `full_dictionary.csv` при запуске
- Docker Compose для быстрого запуска

## Демо-данные

В папке `demo_data` лежат три демо-словаря:

- `demo_kerch_dictionary.csv`
- `demo_mironov_dictionary.csv`
- `demo_pop_dictionary.csv`

В каждом файле по 200 строк. Это не исходные словари, а учебные данные с такой
же структурой колонок. Они нужны, чтобы можно было проверить импорт, базу данных
и поиск без публикации авторских материалов.

## Запуск

Нужны Docker и Docker Compose.

```bash
docker-compose up --build
```

После запуска сайт будет доступен по адресу:

```text
http://127.0.0.1:5003
```

PostgreSQL также доступен с компьютера, например через DBeaver:

```text
Host: localhost
Port: 5432
Database: rusindb
User: postgres
Password: toor
```

При первом запуске приложение само соберет `full_dictionary.csv` из демо-файлов
и загрузит данные в таблицы.

## Структура данных

После загрузки в базе появляются таблицы:

- `kerch`
- `mirinov`
- `pop_rus_ua_ru`
- `rusword`

В демо-режиме загружается 600 записей: по 200 из каждого словаря.
